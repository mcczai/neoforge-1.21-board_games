## 5. 平衡验证与构筑流派（标准对局：10 法力 / 30 生命 / 50 回合）

### 5.1 50 回合内必分胜负（三重保险）

- **快攻线**：无干扰 goldfish 约 9-11 回合斩杀 30 血（T1 骷髅/僵尸小崽子 2/1 → T2 放冷箭的掠夺者 → T3 午夜俯冲的幻翼冲锋 → T4-6 直伤连拍 + 全员上头药水 → T9-11 收割；劫掠兽冲锋不能打脸后略慢 1 回合）
- **控制线**：27 张牌库 ≈ 20-24 回合抽干（起手 4 + 每回合 1 + 经验满满/金苹果/我看着你过牌）→ 疲劳递增：第 8 次疲劳累计 36 伤 ≥ 30 → **≤35 回合必分胜负**
- **保险丝**：回合上限 50（`DuelConfig.maxTurnLimit`，已实现）——即使双方无限治疗，50 回合按血量判胜/平局

### 5.2 双方都有对应解法（解牌矩阵）

| 构筑 | 克制它的解 |
|---|---|
| 快攻铺场 | 嘲讽（雪球投手/激光眼守卫者/铁憨憨/移动城墙）、AOE（嘶嘶苦力怕亡语/飞来横祸/TNT 秘密）、治疗（咕噜一口治疗水/金苹果/我还不能死！）、反伤（仙人掌盆栽/岩浆块磨损低攻生物） |
| 控制拖疲劳 | 冲锋直脸（午夜俯冲的幻翼/鞘翅）、风怒（烈焰人/恼鬼/连刺三叉戟）、潜行首伤免（末影人）、直伤（不怀好意的药瓶/一桶滚烫的爱）、成长流（拖越久生物越大）、地雷陷阱（惩罚每张出牌） |
| 成长组合（叠增益） | AOE 清场（成长生物前期 1/1 极脆）、点杀（放好你的铁砧/火气弹）、风怒抢先（3 血内生物扛不住两次攻击）、绊你一脚（冻结） |
| 陷阱猜谜 | 秘密上限 3 且一次性；用低费牌试探（咩咩羊/咔咔响的骷髅试秘密）；起飞！免疫陷阱伤害；"我看着你"只赚牌不亏场 |
| 装备流 | 反伤/反击磨损耐久（耐久随受击递减）、放好你的铁砧直杀本体、TNT/苦力怕全场伤害磨损全部装备、嘲讽装备可被风怒双杀 |

### 5.4 与 P1 实现的兼容性

- P1 内建技能子集（`CARD_DESIGN.md` §7）按前缀匹配：全部 1-4 费魔法与陷阱沿用可解析 id（`heal_3`/`harm_3`/`fire_3`/`lava_5`/`draw_2`/`mana_1`/`golden_heal`/`pearl_strike`/`totem_protect`/`secret_mine|arrow|tnt|wither|sculk`/`cactus_thorns`），P1 可直接打出
- **放好你的铁砧**（id `secret_arrow`）P1 即按"对方召唤物上场→该召唤物 3 伤"运行，与 v3 描述完全一致；原 `anvil_N` 点选路径保留在代码中但本卡池不再引用
- `mana_1`（红石快充）P1 仅 +1 法力，P2 技能定义扩展为 `[add_mana 1, draw 1]`
- `secret_freeze`/`secret_draw`/`secret_dispenser`/`secret_magma` 为 P2 新秘密：P1 会进秘密区但无触发逻辑（安全占坑）；`buff_all_atk_1`/`buff_atk_3`/`heal_all_2`/`aoe_enemy_2`/`silverfish_growth`/`pillager_shot`/`vex_barrage`/`dragon_breath` 为 P2 新技能，未实现前按站场白板兜底
- 装备 10 张沿用 P1 内建机制（`equip_atk_N`/`equip_guard`/`equip_ranged`/`equip_elytra`/`equip_trident`/`equip_taunt`/`equip_netherite`）；`mace` 的 `equip_atk_5` 可直接走 `equip_atk_*` 规则
- 未知 skill 一律按召唤卡站场兜底 → 54 张全部可被 P1 代码打出
